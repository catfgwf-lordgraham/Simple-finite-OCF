# Simple-finite-OCF
This is an OCF function... but instead of being infinite, it's finite.
This function isn't very powerful.
**Ψfin(x) = x+1**

**Ψfin(X+Ω) = Ψ(X+Ψ(X+Ψ(X)))**

**Ψfin(Ω [op.] Ω) = Ψfin(Ω [op-1.] Ω [op-1.] Ω)**

**Ψfin(XΩ) = 3^X**

**Ψfin(Ω^x) ≈ 27^(x-2)**

**Ψfin(Ω^^Ω) ≈ 27^^3**

**Ψfin(Ω_2) = Ψfin(Ω^^^Ω) ≈ 27^^^3**

**Ψfin(Ω_n+1) = Ψfin(Ω^^^^^...(Ω_n arrows)...^^^^^Ω) ≈ {27, n, 1, 2}**

**#_1(0) Ω_(#_1(0)), Ψfin(#_1(0)) ≈ {27, 3, 2 , 2}**

**#_n+1(0) = #_n(#_n+1(0)), Ψfin(#_n(0)) ≈ {27, 3, n, 2}**
